1.  What is Galaxy?
Galaxy is a complete stock and order management system designed for retail businesses in Sri 
Lanka. It runs entirely inside a single web page — no internet connection, no installation, and no 
server required. Open the file in any modern browser and the system is ready to use.
Galaxy is built to be simple enough for non-technical business owners while being powerful 
enough to manage inventory, orders, staff, and financial reporting in one place.
What Galaxy can do
›  Manage product inventory across multiple warehouses
›  Record and track customer orders from placement to delivery
›  Generate sales, stock, customer, staff, and finance reports
›  Control what each staff member can see and do based on their role
›  Display client branding — logo, business name, and category — throughout the system
›  Show announcement banners and image slides for internal communications
System at a glance
ItemDetail
File typeSingle HTML file — open in any browser
Pages
12 pages: Login, Dashboard, Item Stock, Add Product, Warehouses, 
Manage Orders, Place Order, Reports, Users, General Settings, Billing, 
Help
FontPlus Jakarta Sans — weights 400 to 900
Session
Login session stays active while the browser tab is open. Resets 
when the tab is closed.

6.2  Product Code
›  The code is auto-generated as soon as a Product Name is typed — built from the first 3 
letters of the name plus a random 4-digit number, e.g. "Sunscreen SPF50" → "SUN4821"
›  The code field remains fully editable — typing in it manually overrides the auto-generated 
value
›  Once edited manually, the code will no longer auto-update if the product name is changed 
afterward
›  "↻ Regenerate" button — generates a brand new random code from the current product 
name at any time, overriding any manual edit
›  Helper text below the field: "Auto-generated from name. You can edit manually."
6.3  Pricing
›  Purchase price (LKR) — the cost price, required
›  Selling price (LKR) — the price charged to customers, required

›  Off (shown in grey when inactive) — the product is hidden from Place Order but still exists in

6.5  Warehouse Quantities
One number field per warehouse, each labelled with the warehouse name and its location in

6.6  Selling Details (auto-calculated)
A read-only summary box that updates instantly as prices and quantities are entered:
›  Profit (Each one) — Selling price minus Purchase price
›  Stock value (Purchase) — Total quantity × Purchase price
›  Stock value (Selling) — Total quantity × Selling price
›  Total quantity — sum of all warehouse quantities combined

›  Go to Inventory → Warehouses

›  Go to Inventory → Add Product
